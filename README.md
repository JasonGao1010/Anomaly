# 数据读取与物理观测

本工作区按当前《AJAE V4 总方案》实现。现有代码提供 206 原始扫描读取、固定世界物体的单帧观测、接地与穿插计算，以及联合观测后的训练筛选。本轮没有生成正式合成数据池或训练模型。

## 输入与处理顺序

1. `src.data.STUSequence(data_root)` 逐帧读取 `train/206` 的 449 帧坐标、强度、标签和位姿。相机位姿按 `inv(Tr) @ pose @ Tr` 转为传感器到世界的变换。
2. `Frame.xyzi` 保留原始文件槽位，`Frame.return_slots` 选出三维坐标非零的实际回波。完整模型输入为 `frame.xyzi[frame.return_slots]`，不按距离、标签或重复坐标删减。
3. `src.data.read_rays()` 从本工作区的 `assets/rays.npz` 恢复原始槽位中的射线起点和方向。该文件来自 `AJAE/assets/rays.npz`，是按 206 拟合的几何参考，不能解释为独立传感器精度证据。
4. `src.render.World` 保存合成版本、原始序列、随机种子及各物体的几何身份和固定世界位姿。时间片段不改变物体存在状态。物体须先按明确提供的条件检查接地和穿插。
5. `render_frame(source, world, rays, response, trace)` 让所有异常共同竞争射线，再与原始背景比较前后关系。最近异常表面无回波时仍遮挡后方物体和背景；未受影响的观测保持不变。
6. `src.data.supervision(observation.frame)` 在联合观测后按三维距离 2.5–50 米（含边界）及有效标签计数。原始标签 0 忽略，2 为异常，其余为正常。有效异常总数不足 5 时整帧监督均为忽略，包括零异常帧；合格帧内的少回波异常保留异常标签。监督数组对应原始槽位，计算模型损失时按同一 `return_slots` 取值。

`point_targets` 只计算逐点有效性，用于离线统计，不替代训练整帧筛选。`Observation.effective_counts()` 在整帧合格后统计各物体的有效异常点，未合格时全部为零。`visible_normal` 表示未被新增物体遮挡的原始正常回波，训练时还须满足距离和整帧筛选。新增异常的语义值为 2，合成身份单独保存于 `object_ids`，不占用原生实例编号。标签、身份、位姿及合成版本均不进入模型输入。

## 必须显式提供的参数

几何和物理观测计算选自 `AJAE/src/render.py`，文件与标签读取约定选自 `AJAE-v3/src/scene.py`。没有运行时导入旧工作区的代码。

| 实现 | 输入与作用 |
| --- | --- |
| `src.shape.Shape` | 基本体的半尺寸、偏移、两个外形指数、朝向、并集／差集／交集，以及扭转、弯曲、锥度和表面起伏参数。保留旧外形表示，不提供随机分布或尺寸范围。 |
| `src.shape.Trace` | 射线采样数、细分与二分次数、最近距离、细分选择系数及法向差分参数。精度须针对实际外形核验。 |
| `src.render.Response`、`Material` | 各线束、距离与入射角区间的返回概率及强度分位数表，材质参数、强度范围、可选量化步长和参数来源。零与一的概率保持精确含义；未采用旧拟合表或自动拟合规则。 |
| `check_grounding`、`ground_object` | 两组接地搜索精度、表面采样数、残差容差、收敛与埋入阈值，以及实际支撑平面、接地点和朝向。 |
| `observed_collision`、`pair_collision` | 已观测结构的世界坐标或另一异常物体；容许穿插距离、外部见证点搜索参数和采样精度。原始结构的选取范围也由调用方提供。 |
| `World` | 合成版本、206 序列身份、随机种子、全部物体，以及射线距离并列的处理容差。 |

依据本轮确认，未定数值均没有 V4 默认值。正式外形分布、放置范围、传感器响应及接纳条件在后续落实时再确认。旧自动生成器、候选位置池、数据分布、训练入口、模型及历史成绩没有迁入。

外形的 `level` 是判断内外的隐式函数，其绝对值不是真实表面距离。穿插计算通过限定欧氏距离内的外部见证点检查边界。接地和物体间检查使用数值搜索与有限采样，不能据此证明任意外形全表面无穿插，也不能检查真实扫描未观测到的结构。正式外形和放置确定后，仍需核验对应精度、实际支撑关系及联合观测覆盖。

## 验证与复算

在工作区根目录运行：

```bash
PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 /home/jasongao/Study/AJAE/.venv/bin/python -m pytest -q -s -p no:cacheprovider tests/test_observation.py
PYTHONDONTWRITEBYTECODE=1 /home/jasongao/Study/AJAE/.venv/bin/python -m src.analyze --workers 6
```

测试中的外形、概率、材质、平面及阈值均用于实现验证，不是正式数据参数。真实扫描测试默认读取 `/home/jasongao/Data/STU`，可通过 `STU_DATA_ROOT` 指定数据根目录；没有真实数据时该项明确跳过。

已完整重读 449 帧；五张分析统计表与迁入前字节一致。实际回波为 56,196,767 个，范围内有效正常点为 54,631,044 个，原生异常为 0。详细分析见 [206 序列报告](results/206/report.md)，正常监督说明已按新版总方案更新。

真实扫描验证在第 100 帧约 12 米处的道路观测上拟合局部平面，固定放置半径 0.4 米的测试球体。第 100、101、102 帧分别产生 91、97、100 个异常回波；背景保持、无回波遮挡、世界坐标球面位置及所提供正常点的穿插检查均通过。这些数字不代表正式数据覆盖。解析椭球、薄层组合外形、坐标变换、概率分箱和整帧筛选另有针对性测试。

直接比较旧外形计算时，三种测试外形各 10,000 个隐式值完全一致，各 64 条射线的命中身份一致，求交距离差异均小于 0.1 微米；两个随机通道在同一身份下的 131,072 个槽位值完全一致。此比较限定于测试外形和精度。
