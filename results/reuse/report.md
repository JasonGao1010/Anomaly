# main 旧样本的三类针对性关系检查

**结论：旧池的回波数量、距离和正常背景覆盖较丰富，已有明确的近邻正常—异常共存样本；但目前不能认定“局部容易混淆、上下文增加判别信息”的第一类样本已经足够。** 先前的 123 组点数、距离匹配只能证明粗观测接近，不能代替这项判断。当前证据支持继续从旧池选取和组织样本，尚不能据此决定必须补生成多少新数据。

本次按用户提出的三类关系检查 main 训练样本。只统计有效回波不少于 5 的对象观测，保持 2.5–50 米有效范围及已定整帧筛选规则。配对双方都从完整植入扫描恢复，标签仅用于离线识别分析对象；没有训练模型、生成新样本或指定新的生成参数。

## 三类关系的实际覆盖

| 样本关系 | 已核查的实际数据 | 当前判断 |
| --- | --- | --- |
| **采样相近，上下文不同** | 检查了此前 123 组同点数、近距离候选的局部几何和周围回波。其中 54 组的空间展布尺度相差至少两倍，8 组至少相差四倍。另检查 185 组旧正常近邻参照，发现部分具有局部形态接近、与周围结构距离不同的候选。 | **尚不能认定数量足够。** 点数与距离匹配没有保证局部形态容易混淆；周围回波不同也没有证明这些差异确实增加类别判别信息。 |
| **位置相近，正常异常共存** | 185 个合格植入版本明确保留了同帧正常参照，涉及 151 簇不同正常点、117 个原始帧。正常点簇与异常观测的水平中心间距为 0.43–3.29 米，中位数 1.65 米；距离中位数差为 0.003–3.010 米，中位数 0.759 米。 | **已有可组织的实际样本。** 它们在同一扫描、相近道路位置和背景中共存；尚未据此认定所有道路位置和背景类型均充分覆盖。 |
| **类别相同，观测条件变化** | 40,152 次合格异常观测，以及在合格植入扫描中完整保留的 7,150 次带实例标识的正常观测，都包含少回波和远距离情况。235/240 个异常版本、52/66 个正常结构标识同时出现过 5–19 回波和不少于 20 回波的观测。 | **点数、距离变化的覆盖较充分。** 不同遮挡程度尚未单独量化，不能只用点数变化或背景删除量替代可见程度。 |

185 组近邻记录来自旧生成过程中的正常参照，全部重新确认双方至少有 5 个有效回波且正常点仍保留。正常簇按多数语义分别为道路 107、建筑 36、围栏 20、汽车 10、人行道 5、植被 5、卡车 1、地形 1。它们提供了多种正常背景，但“道路点簇”不等于已经确认的路缘边界，“建筑／围栏点簇”也不等于已经验证了连接或延续关系。

这 185 组是已有参照记录中确认的数量，不是整个旧池中所有可配对关系的上限。没有把不同合成版本或同一结构的相邻帧当成独立场景。

## 两类标签是否都覆盖困难观测

正常列按“原始帧＋语义类别＋实例编号”计一次，异常列按“固定物体版本＋原始帧”计一次。正常路面、建筑等没有实例编号的背景点仍保留在训练扫描中，但不计入下表的正常对象观测数。

| 观测条件 | 正常对象观测 | 异常对象观测 |
| --- | ---: | ---: |
| 总计 | 7,150 | 40,152 |
| 5–19 个有效回波 | 2,384 | 14,838 |
| 20–99 个有效回波 | 2,272 | 13,961 |
| 不少于 100 个有效回波 | 2,494 | 11,353 |
| 距离中位数小于 10 米 | 870 | 12,992 |
| 距离中位数为 35–50 米 | 996 | 4,463 |
| 同一标识同时出现少回波与较多回波 | 52/66 个结构标识 | 235/240 个物体版本 |

这里沿用旧统计中的 5–19 回波、35–50 米描述区间，没有将它们设成新的训练匹配阈值。正常与异常都有稀疏和远距观测，支持组织第三类关系，避免让这些条件只出现在异常一侧。两类观测数量并不平衡；表中正常结构也共享同一条 206 背景轨迹。

已有 1,288 个合格异常扫描没有改变原始实际回波，可以提供弱背景变化样本。这个数字描述背景变化，不表示异常物体无遮挡，更不能当作遮挡程度分布。

## 点数和距离相近，局部形态是否也相近

本轮从真实保存回波重算了局部几何。空间展布尺度定义为点到自身点集中心的均方根距离，单位为米；它描述点集占据多大空间，不受整体平移和旋转影响。形态还通过点集沿不同方向的分散程度，描述其偏向线状、面状或体状的程度。

| 检查量 | 123 组原有粗匹配候选 | 185 组旧近邻参照 |
| --- | ---: | ---: |
| 回波数完全相同 | 123 组 | 17 组 |
| 双方点数较大值／较小值的中位数 | 1.00 | 3.83 |
| 空间展布尺度较大值／较小值的中位数 | 1.75 | 1.61 |
| 空间展布尺度至少相差两倍 | 54 组 | 57 组 |
| 强度中位数绝对差的中位数 | 0.0894 | 0.0589 |

这些量说明粗匹配之后仍需检查局部几何和强度。两倍、四倍只是描述差异的统计分段，不是“容易混淆”的正式判定线。少量点计算出的形态描述也会随采样变化，不能用单个数值判定模型是否会混淆。

185 组旧参照还有一个范围区别：正常方是保存的一簇选定正常点，异常方是物体的有效观测。正常点簇以外可能还有大量邻近回波。因此，选中正常簇只有 5–8 个点，不代表完整局部空间内只有这些点。要判断第一类样本，双方必须使用可比的局部观察范围，并检查扩大范围后实际增加了哪些关系。

旧记录没有系统区分“连接、延续、遮挡”三种关系，也没有验证使用上下文后比只看局部更容易判别。这是当前不能宣称第一类样本已经足够的直接原因，不能把它改写成底层点云中不存在这些关系。

## 判断与下一步

main 旧样本可以支撑第二类和第三类关系的初步组织。当前最需要补齐的是**第一类关系的筛选证据**：哪些正常—异常候选在可比局部范围内确实接近，周围结构又提供了什么额外区别。第一类不应只按点数、距离最近来确定，也不应把背景邻点数量不同直接当成判别信息有效。

下一步应先从已经存在的近邻候选及更广旧池中整理这类关系，同时保留正常独立物体。完成这一步后再统计剩余空白，才能判断需要补生成什么。当前不新增生成配额，不恢复全因素排列，也不把用户排除的观测条件重新列为补充目标。

## 数据与复核来源

- [全部异常观测](frames.csv)：206 的 107,760 个保存扫描，其中 40,152 个满足整帧筛选。
- [物体版本](worlds.csv)：240 个训练版本的外形、放置、旧参照记录；201 验证版本继续独立列出。
- [正常对象观测](normals.csv)：7,150 次正常观测及完整保留它们的合格植入版本。
- [点数与距离候选](matches.csv)：123 组粗匹配关系。
- [局部形态与周围回波复算](pairs.csv)：123 组粗匹配候选和 185 组旧近邻参照，共 308 组。
- [汇总](summary.json)与[分析实现](../../src/reuse.py)：统计来源及计算过程。

全池的来源、标签、整帧筛选和两处文件重复关系沿用并重新核对了先前的实际数据读取。本轮局部与上下文复算覆盖上述 308 组，并未穷举旧池中所有可能的正常—异常组合。场景中未观测到的连接和遮挡无法由这些统计确定；没有模型实验支持“上下文已提高分类性能”的结论。

0.5 米和 2 米仅沿用 main 旧分析中的邻域观察尺度，用于描述周围实际回波，不作为新生成参数。已有物理来源信息继续保留在版本表和汇总中，本轮没有改动旧点云或物理参数。
