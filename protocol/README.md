# 单帧 STU 异常分割研究协议

当前研究对象是一张 STU 激光雷达扫描中的逐点异常。输入为当前扫描的坐标和原始回波强度，输出为同一扫描实际回波的异常分数，分数越高表示越异常。

当前主线为：每个固定物体世界渲染完整正常源序列，每帧作为独立样本。首轮实验数据已经冻结：保留全部 32 个基础世界，按预定八次预算补充 8 个世界，训练与合成验证各 20 个，共 22,620 帧。训练合格低矮远距由 2 个世界增至 6 个，合成验证新增 4 个低矮异常与邻近正常凸起的有效搭配。新增世界完成了 41 张固定完整扫描的监督检查。基础数据保持不变，V1 的模型、训练、推理与评价入口、全量离线监督及隔离实现检查均已完成；当前暂停，等待用户逐文件审查并明确确认，才启动正式一轮。

历史开发池 `results/synthetic/v1/` 保留 32 个训练世界、8 个合成验证世界，共 19,824 帧。它已使用 val19 聚合标签统计生成与选样，继续作为隔离的开发对照。当前实验入口为 `results/synthetic/experiment/`，按原顺序引用 `results/synthetic/candidates/` 中的 32 个基础世界，再追加成功补充；不复制、重渲染或淘汰基础世界。当前 40 个世界的生成和选样只使用正常来源、射线和预先规定的内容条件，不读取 val19 参考包络或拟合分布差异。

V1 使用 LitePT-S 提供场景上下文，以完整的逐点正常／异常检测为主任务；边界距离、采样归一化几何和正常表面预测提供三项增强。关闭增强分支后，场景编码、逐点恢复和检测头仍然可独立前向和反向传播。当前没有正式训练检查点或真实验证成绩，隔离短检查的权重全部丢弃；三项增强的真实迁移价值仍待实验验证。固定训练 10 轮的设定已撤销，本版正式命令只允许完成一轮。

机器可读定义在 [spec.json](spec.json)，读取和必要语义检查由 [src/protocol.py](../src/protocol.py) 完成。当前格式为 `stu-single-frame`，格式版本为 1。

## 单帧读取和模型输入

[STUSequence](../src/scene.py) 通过 `source_frame(frame_id)` 返回一个 `SourceFrame`。索引和迭代同样返回原始单帧。

`SourceFrame.xyzi` 保存完整原始文件槽位，形状为槽位数乘 4，数据类型为 `float32`。`real_slots` 按原始顺序列出坐标不全为零的实际回波槽位。零坐标占位槽继续保存在源数据中，进入模型时通过 `real_slots` 排除。强度保持原值，不能预设它严格位于 0 到 1 之间。

模型可读的基本数组是：

```python
x = frame.xyzi[frame.real_slots]
```

语义标签、实例标签以及依赖标签计算的几何量仅用于监督或诊断，不能作为推理输入。用 `label_mode="forbidden"` 读取源数据时，读取器不打开标签文件。

源对象保留官方坐标及特征的原有计算能力，供数据核对和外部方法适配使用：`coordinates` 按发布位姿计算，`features` 包括原始强度及相对扫描坐标均值的距离。它们是辅助数据表达，不改变当前模型以单帧传感器坐标和强度为输入的任务定义。官方评价距离始终来自 `xyzi[:, :3]`，不能用世界坐标范数代替。

发布标签的低 16 位是语义，高 16 位是实例。原始打包标签完整保留。合成训练的正常监督依据 `normal_semantic_class_map` 中的有效类别，原始忽略类别保持忽略。异常监督只由渲染器的实际插入掩码定义，不能将正常源中的原始语义 2 直接解释成插入异常。

读取示例：

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m src.scene \
  --data-root /home/jasongao/Data/STU --partition val \
  --sequence 125 --frame 0 --labels required
```

## 预测身份和存储

[src/data.py](../src/data.py) 中的 `FramePrediction` 使用以下字段：

```python
FramePrediction(
    partition,
    sequence_id,
    frame_id,
    source_slot,
    anomaly_score,
)
```

每个分数对应一个明确的原始文件槽位。保存和加载时都必须验证：

- 分区、序列号和帧号与传入的 `SourceFrame` 一致。
- 槽位无重复，且其集合恰好等于 `SourceFrame.real_slots`。
- 分数是有限的 `float32`；生产端显式决定精度转换，存储端不静默量化。
- 分数可以为负，也可以超过 1；评价使用原始数值的排序。

生产端可以采用任意点行顺序，但必须同时保存对应槽位。`restore(source)` 按槽位放回完整原始顺序，并将零坐标槽的分数填为 0。依赖数组行号而忽略槽位身份的结果不能进入评价。

`save(path, source)` 不覆盖已有预测；`load(path, source)` 不仅检查压缩包字段，也重新核对真实源扫描。当前存储格式是 `stu-frame-prediction`，不接受其他任务格式作为当前结果。

统一目录为：

```text
<predictions>/val/<sequence>/<frame:06d>.npz
```

各模型或消融实验分别使用自己的预测根目录。V1 的真实预测目录为 `results/v1/predictions/real/val/`；合成预测按世界分目录保存，另绑定实际检查点和实验根清单。正式训练尚未执行，当前这些正式预测尚不存在。

## 官方评价和误差归属

[src/evaluate.py](../src/evaluate.py) 保留 [STU 官方评价器](../vendor/stu/compute_point_level_ood.py) 的点集和阈值定义：

- 点到当前传感器的距离满足 `2.5 <= r <= 50` 米。
- 语义 0 忽略，语义 2 为异常，其余有效语义为正常。
- 距离过滤后异常点少于 5 个的帧整体不进入正式指标。
- 所有合格帧的全部有效点合并计算指标，不平均逐帧或逐序列指标。

平均精确率 AP、排序区分指标 AUROC、以及高召回工作点的正常误报比例 FPR95 以百分数报告。FPR95 使用官方保留的 ROC 阈值节点中召回率严格大于 95% 的第一个节点。相同分数的点必须整体进入或离开检测集合。

低误报工作点使用完整官方点集上实际误报比例不超过 1% 时的最高召回率；召回率相同时选择最早达到该召回率的阈值。如果没有异常点能在该条件下检出，阈值记录为空，含义是拒绝全部点。子组统一使用这两个全局工作点。

指标实现保留精确的单精度排序，并采用磁盘临时数组就地排序和分块累计；不把分数量化到直方图。官方评价器保留为独立核对依据。

`APAttribution` 记录每个异常分数对应的全局精确率及所需误报比例。对异常点 `i`，全局同分组全部纳入后的精确率记为 `P_i`，异常点总数记为 `N_A`。其失分为 `(1-P_i)/N_A`，全部异常点的失分之和应为 `1-AP/100`。任意互斥分组可以据此汇总对全局 AP 的失分贡献。

所需误报比例按分数大于或等于该异常点分数的正常点数量除以全局正常点数量计算。它与 AP 失分都来自同一个全局排序。当前模块提供这些通用计算，尚未实现图谱的条件匹配、序列重采样及贡献裁决。

完整开发集评价示例：

```bash
PYTHONDONTWRITEBYTECODE=1 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  .venv/bin/python -m src.evaluate --data-root /home/jasongao/Data/STU \
  --predictions results/predictions/<model> --output results/evaluation/<model>
```

可用 `--sequence` 运行明确标记的开发子集。完整评价要求所选序列的每个原始帧均有符合身份约定的预测。临时排序文件使用结束后即释放。大体积评价必须根据当时 Windows E 盘空间保留至少 10 GB 余量。

## 单帧真实几何画像

[src/profile.py](../src/profile.py) 保留单帧统计算法，包括异常点数、距离、强度、最近正常点距离、正常邻域、同实例最近邻、可见实例尺寸、协方差形态和地面关系。几何量在当前扫描中计算，源点身份贯穿统计过程。

画像描述全部原始帧的实际回波，范围比官方指标点集更广。原始异常点数和官方范围内异常点数分别保存；符合官方帧门槛的计数另行汇总。忽略点和范围外点的描述性统计不能混入正式 AP 失分结论。

实例几何与地面估计保留原有可靠性规则。无可靠地面拟合时，高度保持缺失并报告原因。异常点实例标识为零时，不假定这些点属于同一个物体；点级和帧级异常统计继续保留它们。

[src/profile_report.py](../src/profile_report.py) 根据实际生成的逐帧记录、逐实例记录和分布累计结果导出 [统计表格](../results/profile/tables)。分位数来自完整加权经验分布，不平均各序列分位数。表格目录保存：

```text
frames.csv
instances.csv
sequences.csv
totals.csv
count_distance.csv
continuous.csv
categorical.csv
bins.csv
reliability.csv
index.csv
method.md
```

CSV 数值列与实现字段直接对应，空值表示缺失或不适用。CSV 本身不保存字体。详细统计定义由生成源写入 `method.md`，修改定义时应修改生成源并重新生成结果。

完整运行示例：

```bash
PYTHONDONTWRITEBYTECODE=1 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  .venv/bin/python -m src.profile --data-root /home/jasongao/Data/STU \
  --output results/profile --workers 12
```

进程数必须依据当时 CPU、内存和其他任务实测状态确定。`--output` 同时决定明细子目录 `records/` 和表格子目录 `tables/`。少量帧检查可使用 `--sequence` 和 `--limit`，并指定独立的 `--output`，避免将子集结果覆盖到完整画像位置。

已有完整明细时，在上述命令中加上 `--tables-only` 可重新汇总并生成表格，无需重新读取原始扫描。表格中的 `index.csv` 使用相对于表格目录的路径指向明细汇总文件。

## 固定世界与冻结单帧数据

[src/render.py](../src/render.py) 保留连续几何、形状族、激光射线、物体放置、地面支持、传感器标定和真实遮挡竞争。`render_frame(source, world, ray_grid, sensor)` 的基本渲染对象是一个 `SourceFrame`；`render_frames` 只是逐个调用单帧渲染的流式工具。

[assets/rays.npz](../assets/rays.npz) 保存独立的射线几何标定数据。`calibrated_ray_grid` 读取该文件，计算束方向、束原点以及原始槽位到射线的对应关系。回波概率与强度规律重新由正常 `train/206` 的全部单帧标定；放置地面的拟合仅使用一张当前正常扫描。物体随后固定在世界坐标中，形状、尺寸、位置、朝向和材质均不随帧变化。

[src/generate.py](../src/generate.py) 提出候选世界，检查完整轨迹中的位置距离及全部帧的已观测障碍物碰撞，再通过 `render_frames` 渲染固定物体。每个已渲染帧写入后重新读取，逐元素核对坐标、强度、打包标签、实际回波槽位和插入、遮挡掩码。没有异常回波的帧仍然写入；物体遮挡原始回波却没有返回信号时，对应槽位及标签清零。

基础 32 世界保留单基元、扁平单基元、两部件接合、弯折及双支腿与横梁等形态。当前入口只执行一次有界补充：训练侧为两个低矮单体、两个低矮弯折组合，目标是合格低矮远距；合成验证侧同样两个单体、两个组合，目标是邻近原生正常凸起参照。类别参数、种子和搜索预算见 `v1.json:proposals`。每个物体的完整局部几何范围包含全部基元及偏移，统一用于尺寸、低矮条件和放置支撑；碰撞检查使用完整形状及其保守范围。组合部件必须连通，贴地后检查完整物体的下界与埋地比例。

放置只使用正常源数据。每个种子固定一个形状和材质，最多提出 192 个支持位置，收集至多 12 个几何合格支持，每处检查三个预定朝向。远距候选从物体中心处于 35–50 米的真实轨迹中，取最接近 36、42、48 米的三个不同帧，复用渲染器的实际形状求交与原始背景遮挡竞争。分别记录包围盒机会、真实前景表面命中和固定信号的最终异常回波；只按真实表面命中排序。原生正常参照则从 `train/201` 的八张固定完整正常扫描中按既有 C3 条件查找，再在参照附近寻找合法支撑；选定参照必须在核对帧中免于遮挡并保持原坐标、强度和标签。

完整渲染后按普通少点、合格远距少点、较密远距、低矮、低矮远距分别记录世界数与帧点贡献。全部基础世界按原顺序保留；新增世界只有同时通过物理检查和预定内容目的才追加。八次尝试完成后按实际成功数冻结，不追加种子或按辅助有效率淘汰。远距至少 20 点只作探索性记录。入选世界里的无异常帧、极少点帧和辅助无效帧全部保留。

当前实验产物集中在 `results/synthetic/experiment/`，根清单引用原基础文件，新增文件如下：

```text
manifest.json
calibration.pt
normal_reference.json
train/supplement_000/{world.json,manifest.json,frames/000000.npz,...}
validation/supplement_000/{world.json,manifest.json,frames/000000.npz,...}
```

根清单的 `planned_candidates` 在执行前记录八个种子；`generation` 保留每次尝试、完整观测、内容核对与失败原因，`splits` 定义最终训练成员。状态为 `frozen`。物理碰撞失败的世界完成整条渲染后保留证据，不列入训练成员；内容目的未实现时同样不追加。每帧采用 `stu-frozen-frame` 无损差量格式，绑定原始扫描、标签、位姿和固定世界，保存变化槽位；未改变的背景引用原始正常扫描。`normal_reference.json` 仅保存绑定正常源身份的参照位置，供本批候选使用，不成为推理输入。

历史开发池采用过 val19 参考轨迹包络和最小总变差选样，相关数值只说明该历史生成流程的行为。其完整配置与参考记录保留在 `results/synthetic/v1/`，生成入口已移除该路径。以下开发池结果仍可用于对照，不能解释为新候选结果。

历史开发池的实际汇总如下；完整逐帧记录和分项差异保存在本地 `results/synthetic/v1/manifest.json` 及各世界清单中。

| 划分 | 世界数 | 单帧数 | 无异常回波的帧 | 插入异常回波数 |
| --- | ---: | ---: | ---: | ---: |
| 训练 | 32 | 14,368 | 9,183 | 111,232 |
| 合成验证 | 8 | 5,456 | 3,642 | 34,951 |

训练候选中 114 个通过检查、14 个被拒绝；合成验证候选中 48 个通过、16 个被拒绝。最终选择将各分项总变差距离的平均值从训练候选集合的 0.1671 降到 0.1032，从合成验证候选集合的 0.0949 降到 0.0794。总变差距离在所采用的统计分箱内取值为 0 到 1；0 表示分箱概率相同，1 表示完全分离。此处每个特征包含缺失值分箱，平均数不能代替逐项判断。

训练集最明显的残差是 `range_step`，即相邻可见帧异常回波中位距离之差的绝对值，再取整条轨迹的中位数。该项总变差距离为 0.8354；32 个训练世界的该量中位数为 0.1710 米／帧，真实参考轨迹为 0.3861 米／帧。该差异与当前观测轨迹有关，不能仅由这个量断言车辆速度是唯一原因。只对具有可靠可见尺寸的帧比较高度分布时，训练集的条件总变差距离仍为 0.3474。当前数据是有限候选下的近似结果，这两项偏差不能被综合均值掩盖；本轮没有修改真实位姿、抽掉原始帧或重定义真实标签来消除它们。

## 损失聚合与可见支持对照

`supervision.loss` 定义当前采用的聚合规则；`src/supervision.py` 中的 `boundary_loss`、`sampling_loss`、`surface_loss` 是可求梯度的 PyTorch 实现。每次调用处理当前小批量的同一视图或同一删减级别：先合并该批点行，再按类别求均值。拼接多个帧时，C2 的 `dense_row` 必须加上各基础帧在批次中的点行偏移，使其仍指向同一帧、同一槽位的基础预测。

| 辅助项 | 点误差 | 聚合规则 |
| --- | --- | --- |
| C1 | 预测距离与既有距离目标的绝对误差 | 有效且目标小于 1 为交界带，等于 1 为饱和区；每个区域内先分别平均正常点、异常点，再对存在类别等权。两个区域均存在时，交界带占 0.75，饱和区占 0.25。 |
| C2 | 稀疏异常概率与停止梯度的对应基础异常概率之差的平方 | 在原有一致性有效掩码内，分别平均正常点、异常点，再对存在类别等权。 |
| C3 | 预测表面位移与既有目标的绝对误差 | 在正式默认可见支持至少 20 的有效掩码内，分别平均正常点、异常点，再对存在类别等权。 |

空类别跳过；C1 空区域跳过后，将剩余区域权重归一化。整项无有效点时返回可反向传播的零；先选有效点再计算误差，不用无效占位值补目标。若同时使用多个视图，同一辅助项对存在有效监督的视图/级别等权平均。三项辅助损失与基础检测损失之间的系数本轮未设定。3∶1 是初始区域权重，未证明最优；所有分组信息和点权重只用于损失，不进入推理输入。

## 开发池的训练内容检查与生成依据

这次检查确认了内容缺口，也保留了有价值的现有观测。不能继续把监督计算正确解释为样本质量已经合格；同样，不能把所有低矮背景描述为缺少正常参照。

[src/coverage.py](../src/coverage.py) 首先读取冻结根清单选中的 40 个世界及其 19,824 帧观测记录，不包含未选候选。训练侧为 14,368 帧、111,232 个异常回波，其中官方距离内为 110,124 个；合成验证侧为 5,456 帧、34,951 个异常回波，其中官方距离内为 34,665 个。无异常帧分别为 9,183 和 3,642。各世界的完整维度、指数、材质、放置语义、倾角及观测背景分类均保存在本地 [结果明细](../results/coverage/v1.json) 的 `worlds` 中；`inventory` 按条件保存帧数、回波数和每个世界的贡献。

“合格”指传感器距离 [2.5,50] 米内至少有 5 个异常回波；“少点”指该范围内 5–19 个；“远距”指清单中异常回波中位距离在 [35,50] 米；“低矮”沿用物体局部完整高度不超过 0.2 米的定义。训练与合成验证中的所有合格帧分别为 2,693 和 943。点数是回波观测数，不是独立物体数；多个世界反复使用同一条正常轨迹，背景也不能按合成帧数视为独立。

C3 的所检低矮异常点在基础／半采样／四分之一视图中的有效数为训练 1,679／839／419，分母为 1,809／906／452；合成验证为 617／308／154，分母相同。训练全部 435 个合格远距异常点及合成验证全部 11 个均在插入前参考点不足 20 时退出。独立读取这些点的原始正常扫描，2 米水平邻域中的不同参考位置为训练 0–18 个，合成验证均为 2 个。例如 `train/world_007/173` 的槽位 78801 有 6 个参考位置，`validation/world_001/585` 的槽位 79884 有 2 个。此处尚未执行参考表面后续几何检查，不能声称把参考下限改小就能获得可靠目标；本轮不改变参考支持条件。

正常参照的定义是：原检测标签为正常，距插入异常实际回波不超过 2 米，C3 有效，且当前点比估计正常表面高 5–20 厘米。这个范围在检查前指定，仅用于观察“凸起仍为正常”的样本，不是路缘识别器或新的异常阈值。所检低矮帧中，训练有 2,376 个这样的正常回波，来自 19 帧、11 世界；合成验证有 154 个，来自 5 帧、3 世界。贡献最多的 5 个训练世界占 87.21%，其中语义 48 有 1,568 点，语义 40 有 173 点，另外还保留车辆、建筑、围栏等正常类别的表面附近回波。若不限制在异常附近，所检低矮世界的完整当前扫描均含此类正常参照。因此，本次否定“所有低矮世界都完全没有合法凸起参照”的概括，但不能据此宣布路缘、复杂坡面或困难负例已经充分覆盖。

几何核对给出了可定位的正负例。同一低矮世界 `train/world_012` 的第 393 帧，异常槽位 109846 的表面位移为 −0.059386 米，参考内点／可见支持为 278／244；附近正常车辆语义槽位 108832 的位移为 −0.182251 米，参考内点／可见支持为 252／217。后者相对表面的凸起更高，但检测标签仍为正常。在 `train/world_002/10` 中，异常槽位 91557 与附近正常语义 48 槽位 93603 的位移分别为 −0.098578、−0.071182 米，两者目标都有效。`checks[*].probes` 保存了 116 次独立 NumPy/SciPy 核对的坐标、平面系数、支撑数及残差，核对差异小于 10⁻⁶ 米。这些是监督几何证据，没有模型输出。

该次检查形成 `v1.json:generation_plan` 的修订依据：保留已有简单形态和正常参照，补充连通组合形状以及距离、朝向和背景搭配；把合格远距、合格少点、低矮合格远距分别作为按世界报告和选择的内容条件。原入口仅要求每世界任意一帧合格，再按照 val19 统计选择世界，不能保证上述交叉条件。当时确定的后续任务是移除参考包络和总变差拟合，实际生成符合来源条件的新候选。上述检查对应 `64f92fe`；新入口及候选实测见后文，开发池本身未改变。

据此区分处理位置：缺少组合形态、远距合格观测只来自很少世界、合成验证低矮远距为空，属于内容与选样问题；远距原始参考支持不足和删减后证据丢失属于观测与监督可用性问题，当前不能据此裁定应放宽阈值；现有点数集中则仍可由后续按世界抽样控制，但不能替代前两类处理。材质尚未发现独立缺口，本轮不同时修改。最终迁移价值仍须由自己的 V1 训练和真实验证回答。

## V1 模型与训练实现

[模型代码](../src/model.py) 的输入只包含当前实际回波及由该扫描计算的无标签几何。LitePT-S 对 0.05 米体素内全部回波求均值，编码场景上下文，再按体素归属返回每个原始点。逐点恢复同时保留该点相对体素均值的三维偏移、原始强度及坐标；体素层不生成检测标签，也不进行标签投票。

局部几何分支在原有完整扫描邻域中，同时读取真实位移与按当前采样尺度归一化的位移，经过共享两层全连接变换，再汇合邻域均值和最大值。尺度无效时，归一化分量为零，真实几何和完整检测输入继续保留。32 通道局部几何与 72 通道场景上下文、逐点坐标强度和体素内偏移融合为 96 通道点特征。边界分支预测 0–1 无符号距离，表面分支预测以米为单位的有正负竖直位移。最终检测头读取这 96 通道特征和两项**预测值**，输出未经逐帧归一化的单精度异常分数。真值和标签可靠性掩码不能进入模型。

`model.enhancements` 分别控制三项增强。全部关闭时，局部增强和两项辅助预测退出计算，完整场景编码、逐点特征和直接检测头仍然存在。这个开关提供结构上可独立使用的基础检测器；本次不训练正式基础版对照。正式 V1 的三个开关均为 `true`，总参数量为 12,723,423。

编码器来自作者发布的 [LitePT 独立实现](https://github.com/prs-eth/LitePT/tree/436d04801c8151faebe66a1b2d368a9711e7e6aa)，没有载入预训练权重。来源、许可证和本机混合精度适配见 [编码器说明](../vendor/litept/README.md)。体素均值采用固定顺序分组求和；相同输入的重复推理须逐元素一致，才能在同一个源帧的多个世界间复用完全相同输入的预测。

短检查确实发现并处理了一项训练／推理差异。作者默认 BatchNorm 在训练时使用当前点云统计，在推理时改用历史滑动统计；同一组短检查权重下，训练远距帧的联合模型检测损失分别为 1.2907（历史统计）与 0.0420（当前统计），仅检测损失模型分别为 1.2773 与 0.0313。保持权重和样本不变的比较将主要差异定位到了统计切换。V1 因此明确设置 `model.backbone.norm_running_stats=false`，训练和推理均使用当前单帧的内部特征统计，保留可学习仿射参数。它不读取其他扫描，也不改变最终分数的全局比较规则；不能据此断言历史统计在其他训练规模或任务中一定无效。

[训练入口](../src/train.py) 将模型输入与监督数组分开传递。基础、半采样、四分之一采样分别前向与反向；只有一致性项读取停止梯度的基础分数。每个视图都计算有效正常点和异常点分别取均值的二分类损失，再对存在的类别等权。C1 保留交界带与饱和区 3∶1，以及区域内部类别等权；C2/C3 保留有效类别等权。一个基础样本的检测损失平均三个参与前向的视图；每个辅助项只平均存在有效正常或异常监督行的视图／配对，空视图不参与。有效但误差恰为零的视图仍计入分母；整项没有有效监督时为零。总损失为检测损失加三项各乘 0.1 的辅助损失。

`98d542e` 的跨视图代码曾固定除以 3 或 2，与已经规定的有效视图平均冲突；该问题影响实际反向和日志，不能只修改说明。现由 `loss_view_weights` 根据有效掩码及正常／异常标签计算权重，`view_losses` 将同一权重用于顺序反向、损失日志和 `check_summary`。例如仅基础视图具有 C1 时，跨视图结果保留其完整损失，不再额外除以三。四个基础样本的梯度累积及每视图内部权重不变。

第一版参数统一记录在 [v1.json](v1.json) 的 `model` 和 `training`，不是通过真实验证指标搜索得到：随机种子 2062028；AdamW；学习率 0.001；权重衰减 0.005；前 100 次更新从约十分之一学习率线性预热，此后恒定；每次一张基础扫描及对应两个视图，累积四个基础样本；梯度范数上限 1；半精度自动混合精度与梯度缩放，预测头和损失使用单精度。一次正式训练遍历预先打乱的全部 8,980 个基础样本，共 26,940 次独立单帧前向、2,245 次更新尝试。缩放器跳过的更新单独计数，不能把尝试数冒充成功更新数。

更新前先解除梯度缩放并计算总范数。范数有限时，使用 PyTorch 原来的裁剪计算；元素有限但总范数非有限时，在裁剪、权重衰减及 AdamW 更新前明确报错。若梯度元素本身非有限，则保留 AMP 跳步，记录 `success=false`、原因与降低后的缩放系数。这个分支区分依据 [PyTorch 的裁剪定义](https://docs.pytorch.org/docs/2.12/generated/torch.nn.utils.clip_grad_norm_.html) 和 [AMP 的更新约定](https://docs.pytorch.org/docs/2.12/notes/amp_examples.html)，没有改变学习率、裁剪上限或正常更新公式。本机 PyTorch 2.12／CUDA 修前复现中，两个有限的 10²⁰ 梯度得到非有限总范数，旧函数却报告成功，参数因权重衰减改变约 5.36×10⁻⁷；这是独立构造的执行反例，不是正式模型训练故障或科学效果结果。
