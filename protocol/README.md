# 单帧 STU 异常分割研究说明

当前研究对象是一张 STU 激光雷达扫描中的逐点异常。输入是当前整帧全部实际回波的坐标与原始强度，每个点的判断可以利用同一扫描的邻域和场景上下文；输出与原始回波槽位对应，分数越高表示越异常。输入单位不是脱离邻域的孤立点。

现有工作已完成真实几何画像、仅用正常来源建立的条件几何探针，以及现有合成数据的内容与插入前后核查。这些结果支持部分局部几何具有弱预测信息，也显示复杂正常结构、稀疏观测和几何解释存在限制。原40世界的样本覆盖已收口，主要正反例和相应验证观测已存在；这不等于变化已经丰富。随后按用户授权完成训练80世界、验证40世界的有界扩充，增加形状内部变化、放置搭配和跨条件观测。当前120世界的文件已冻结；最新阶段决定撤回数据准备已可完成的判断，继续按论文核心条件建设与验收，模型设计保持暂停。正式模型尚未设计或实现，网络结构、监督目标和损失均未确定。已退出的旧模型原型不能作为正式 V1 的默认架构或继续训练起点。

旧模型原型完成过一轮完整合成与真实评价；随后同结构辅助监督整体开启／关闭的 A、B 各完成一轮训练，配对评价尚未完成即按用户要求主动终止。旧训练、模型、离线监督及专用诊断体系已退出；仅保留有解释价值的历史小型图表，见本文末尾。没有辅助监督有益或有害的受控评价结论。

当前研究问题与数据边界在 [spec.json](spec.json)，由 [src/protocol.py](../src/protocol.py) 读取。[data.json](data.json) 保存现有数据生成和几何核查所需参数。其 `geometry` 中的 `sampling_scale`、`boundary`、`levels`、`sampling`、`surface` 服务于数据诊断，不规定新模型必须采用哪些输入或辅助任务。冻结清单内原有配置、路径和历史命名保持原样，它们记录当时的生成过程。

## 当前数据构造与验收定义

最终只保留训练240个、合成验证120个完整世界。旧世界与新世界共同参与选取，计入同一总数；原80／40和原验证20世界均不再享有额外保留配额。正常来源仍分别为206和201，完整世界及其全部源帧不跨两侧分配。最终清单和读取验证完成后直接删除多余世界，不重抽回波或裁掉困难帧。

主构造空间为五类实际结构、两档局部高度和三类原始正常背景，共30格。每格最终训练8个、验证4个世界。五类结构依次以多分支、多接触、薄片、细长、其余块状作互斥主类；原有非互斥物理描述仍分别报告。分类根据实际占据几何而非模板名，两种空间分辨率不一致时记为未确定。两档高度为物体局部高度不超过0.2米与超过0.2米，不解释为真实重力方向高度。三类背景为两项原始几何同时不超过206条件参考第10百分位的平滑正常、至少一项达到第90百分位的起伏正常，以及局部邻域不足8点的稀疏正常；201只应用206参考。

每世界至少需要一个实际扫描，包含5条距离范围内唯一异常射线，以及相距2米内至少5个原坐标、强度和正常标签不变的同类正常位置，才可计入对应背景格。一世界只分配到一格。每格训练至少6个独立几何父项，验证4个；优先在至少3个支撑区域分布，并报告重复观测、父项、区域和源帧集中度。一个世界的背景类型可以随观测变化，指定主格不会改变其余帧的内容或标签。

候选预算为每格训练24个、验证12个，共最多1080个新世界提案；这是最终配额的三倍尝试余量，现有合格世界同时纳入候选。每父项至多3次形状尝试、192次支撑提案及12个局部合法支撑候选，每生成世界上限16 MiB。先根据原始正常几何选择空间分散的背景簇，再在附近寻找合法放置；精确射线相交机会用于优先选择，未满足远距机会的合法世界仍可进入候选池。全部候选完成真实渲染后按同一规则选取。物理不合法的提案拒绝，不修改返回概率、不补点、不重复随机回波、不使用模型分数或val19异常分布。

格内另外核查距离、可见支持和弱背景变化。近、中、远距离为[2.5,10)、[10,35)、[35,50]米，采用实际异常回波中位距离。支持分0、1—4、5—19和至少20条实际物理射线；零回波没有可见距离，范围外另报。201中4帧的重复文件槽位在物理覆盖中去重，官方评价仍保持原槽位定义。30格并不声称所有距离、点数、形态的笛卡尔组合都已被物理实现。

弱背景变化主定义已获用户确认：至少5条可见异常射线，同时被替换或消失的原背景射线不超过4条。新增命中、替换原回波、原回波消失分别统计，并报告射线重叠比例、方位与仰角跨度、射线格连通分量。这描述已观测背景变化，不是异常自身被背景遮住的比例。零回波与1—4回波不能计入可见弱背景变化证据。

| 核心内容 | 最低观测关系 |
| --- | --- |
| 同一几何的观测变化 | 同一固定世界在近、中、远均至少5个不同源帧；物体局部视线方向跨度至少30°，可见点所在八分区组合至少2种，再统计独立父项数 |
| 距离与支持交叉 | 近距1—4回波、远距至少20回波分别核查；低矮物体在近、中、远分别核查 |
| 实际物体结构 | 紧凑、细长、薄片、多分支及距局部最低支撑平面1厘米截面的多接触区域，使用实际几何与双分辨率一致性 |
| 弱背景变化 | 可见异常存在，同时已观测背景射线改动少 |
| 困难正常与非极端异常 | 三类原始正常与两量均在206条件参考第10—90百分位区间的异常，在相同距离与竖直射线分箱且相距2米内配对；每类至少跨2个距离段 |
| 保留正常点 | 坐标、强度与标签不变，但残差变化超过0.01米或法向变化量改变超过0.01弧度，每观测至少5点 |

这些核心项仍按补充前的标准检查：训练至少6个父项、3个支撑区域、30个不同源帧及世界帧、150条相关异常回波；验证至少4个父项、3个区域、20个源帧及世界帧、100条回波。每父项至少5个合格不同源帧，单父项相关回波贡献最多35%，单区域最多50%。区域按世界坐标10米网格及平移5米网格检查。配额完成不替代核心项通过；未通过继续停留在数据阶段，不生成模型有效性的结论。

完整世界选择同时约束30格配额与上述核心证据。候选池通过某项并不保证删减后的360世界仍通过，因此选择时直接约束父项的重复观测、源帧并集、两个网格的区域数、相关回波数与最大贡献，并在写入最终成员前按报告公式重新核验。选择与报告共用同一内容统计定义，不以加权目标中的偏好代替最低覆盖条件。

详细几何固定选取每世界距离、回波数与弱背景变化联合分层中的3个等距源帧，另外包含已有正常见证帧及前后各2帧。邻域始终由完整扫描建立。用于确认原始背景类型的邻近正常位置全部查询并按实际位置去重；插入后的正常几何变化诊断最多按槽位等距选512点，异常查询覆盖全部唯一射线。困难配对每观测至少3个中央区间异常与5个同类正常。缺失与没有正常参考分别记录；所选扫描比例不扩展为全池几何比例。

训练取样预案先给30个指定组合相同概率，再在格内将80%分配给已有距离、点数、弱背景变化状态，余下20%覆盖完整世界的全部帧。状态内部兼顾支撑区域和几何父项，并按平均异常点数平方根的倒数抑制单一大物体回波占比。零回波、范围外和几何不可计算帧均有非零概率。只检查真实输入帧与异常回波的预期贡献，不把这当成梯度平衡或训练效果。

## 单帧读取与输入身份

[STUSequence](../src/scene.py) 通过 `source_frame(frame_id)` 返回一个 `SourceFrame`。索引和迭代同样返回原始单帧。

`SourceFrame.xyzi` 保存完整原始文件槽位，形状为槽位数乘 4，数据类型为 `float32`。`real_slots` 按原始顺序列出坐标不全为零的实际回波槽位。零坐标占位槽继续保存在源数据中，构造研究输入时通过 `real_slots` 排除。强度保持原值，不能预设它严格位于 0 到 1 之间。

单帧可读的基本数组是：

```python
x = frame.xyzi[frame.real_slots]
```

语义标签、实例标签以及依赖标签计算的几何量仅用于监督或诊断，不能作为推理输入。用 `label_mode="forbidden"` 读取源数据时，读取器不打开标签文件。

源对象保留官方坐标及特征的原有计算能力，供数据核对和外部方法适配使用：`coordinates` 按发布位姿计算，`features` 包括原始强度及相对扫描坐标均值的距离。它们是辅助数据表达，不改变当前研究以单帧传感器坐标和强度为输入的任务定义。官方评价距离始终来自 `xyzi[:, :3]`，不能用世界坐标范数代替。

发布标签的低 16 位是语义，高 16 位是实例。原始打包标签完整保留。合成训练的正常监督依据 `normal_semantic_class_map` 中的有效类别，原始忽略类别保持忽略。异常监督只由渲染器的实际插入掩码定义，不能将正常源中的原始语义 2 直接解释成插入异常。

读取示例：

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m src.scene \
  --data-root /home/jasongao/Data/STU --partition val \
  --sequence 125 --frame 0 --labels required
```

## 预测身份和存储

[src/data.py](../src/data.py) 中的 `FramePrediction` 使用以下字段：

```python
FramePrediction(
    partition,
    sequence_id,
    frame_id,
    source_slot,
    anomaly_score,
)
```

每个分数对应一个明确的原始文件槽位。保存和加载时都必须验证：

- 分区、序列号和帧号与传入的 `SourceFrame` 一致。
- 槽位无重复，且其集合恰好等于 `SourceFrame.real_slots`。
- 分数是有限的 `float32`；生产端显式决定精度转换，存储端不静默量化。
- 分数可以为负，也可以超过 1；评价使用原始数值的排序。

生产端可以采用任意点行顺序，但必须同时保存对应槽位。`restore(source)` 按槽位放回完整原始顺序，并将零坐标槽的分数填为 0。依赖数组行号而忽略槽位身份的结果不能进入评价。

`save(path, source)` 不覆盖已有预测；`load(path, source)` 不仅检查压缩包字段，也重新核对真实源扫描。当前存储格式是 `stu-frame-prediction`，不接受其他任务格式作为当前结果。

统一目录为：

```text
<predictions>/val/<sequence>/<frame:06d>.npz
```

后续模型分别使用自己的预测根目录；上述约定保留为通用数据与评价接口。旧原型的模型权重及完整预测已经退出当前工作区，历史图表不构成现存预测集合。

## 官方评价和误差归属

[src/evaluate.py](../src/evaluate.py) 保留 [STU 官方评价器](../vendor/stu/compute_point_level_ood.py) 的点集和阈值定义：

- 点到当前传感器的距离满足 `2.5 <= r <= 50` 米。
- 语义 0 忽略，语义 2 为异常，其余有效语义为正常。
- 距离过滤后异常点少于 5 个的帧整体不进入正式指标。
- 所有合格帧的全部有效点合并计算指标，不平均逐帧或逐序列指标。

平均精确率 AP、排序区分指标 AUROC、以及高召回工作点的正常误报比例 FPR95 以百分数报告。FPR95 使用官方保留的 ROC 阈值节点中召回率严格大于 95% 的第一个节点。相同分数的点必须整体进入或离开检测集合。

低误报工作点使用完整官方点集上实际误报比例不超过 1% 时的最高召回率；召回率相同时选择最早达到该召回率的阈值。如果没有异常点能在该条件下检出，阈值记录为空，含义是拒绝全部点。子组统一使用这两个全局工作点。

指标实现保留精确的单精度排序，并采用磁盘临时数组就地排序和分块累计；不把分数量化到直方图。官方评价器保留为独立核对依据。

`APAttribution` 记录每个异常分数对应的全局精确率及所需误报比例。对异常点 `i`，全局同分组全部纳入后的精确率记为 `P_i`，异常点总数记为 `N_A`。其失分为 `(1-P_i)/N_A`，全部异常点的失分之和应为 `1-AP/100`。任意互斥分组可以据此汇总对全局 AP 的失分贡献。

所需误报比例按分数大于或等于该异常点分数的正常点数量除以全局正常点数量计算。它与 AP 失分都来自同一个全局排序。这些计算描述输出排序的错误归属，不能单独确定网络内部机制或错误的因果来源。

完整开发集评价示例：

```bash
PYTHONDONTWRITEBYTECODE=1 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
  .venv/bin/python -m src.evaluate --data-root /home/jasongao/Data/STU \
  --predictions results/predictions/<model> --output results/evaluation/<model>
```

可用 `--sequence` 运行明确标记的开发子集。完整评价要求所选序列的每个原始帧均有符合身份约定的预测。临时排序文件使用结束后即释放。大体积评价必须根据当时 Windows E 盘空间保留至少 10 GB 余量。

## 固定世界与冻结单帧数据

[src/render.py](../src/render.py) 保留连续几何、形状族、激光射线、物体放置、地面支持、传感器标定和真实遮挡竞争。`render_frame(source, world, ray_grid, sensor)` 处理一个原始单帧；`render_frames` 逐帧流式调用。物体一旦放置，形状、尺寸、世界坐标位置、朝向和材质均不随帧变化。

[assets/rays.npz](../assets/rays.npz) 保存射线几何标定；`calibrated_ray_grid` 给出束方向、束原点及原始槽位与射线的对应。回波概率与强度规律由正常 `train/206` 的全部单帧标定；放置地面仅从一张当前正常扫描拟合。包围盒射线机会、真实物体表面交点与最终返回信号是三个不同阶段，不能互相替代。

[src/generate.py](../src/generate.py) 只使用正常源提出固定世界，检查支持、整条轨迹的距离和已观测障碍物碰撞，再执行完整渲染。每个已渲染帧写后重新还原，核对坐标、强度、打包标签、实际回波槽位、插入和遮挡掩码。物体遮挡原始回波却没有返回信号时，对应槽位及标签清零；没有异常回波的帧仍保留。既有物理检查只能约束扫描中已观测到的背景，不能声称掌握所有未观测表面。

原40世界的 [实验根清单](../results/synthetic/experiment/manifest.json) 按原顺序引用 [基础池](../results/synthetic/candidates/manifest.json) 的 32 个世界，再追加 8 个补充世界，状态为 `frozen`。两侧各 20 世界，共 22,620 帧。每帧采用 `stu-frozen-frame` 无损差量格式，绑定原始扫描、标签、位姿和固定世界；未改变的背景引用原始正常扫描。`FrozenDataset` 按根清单读取，`FrozenFrame` 按原始槽位还原完整扫描。冻结世界及其原始配置记录不因退出旧训练体系而改变。

基础 32 世界包含 16 个单基元、4 个两部件接合、8 个弯折组合、4 个双支腿与横梁组合。全部组合通过连通性核对，完整尺寸包含所有部件、偏移及空隙。每侧有 8 个完整局部高度不超过 0.2 米的低矮物体；仅看第一部件高度可能错分低矮条件。原始背景没有因放置而平整，保留原有正常结构。

八次补充在生成前固定种子及有限搜索预算，不更换失败种子或追加尝试。训练侧两个低矮单体、两个低矮弯折组合，提出目的为合格低矮远距；验证侧同样四个不同物体，目的为与原生正常凸起参照共同可见。每个种子固定形状与材质，最多提出 192 个支持位置、收集 12 个几何合格支持，每处检查 −30°、0°、30° 三个朝向。远距候选按真实轨迹中最接近 36、42、48 米的检查帧表面命中排序，固定信号只用于记录与核对，不用于挑选有利随机结果。

验证参照从正常 `201` 的八张预定完整扫描寻找。其定义是有效正常标签点相对可靠正常表面高 5–20 厘米，插入后仍在实际异常回波两米内共同可见；预选位置的坐标、强度和标签必须精确保留。这是几何参照，不是路缘类别或模型困难真值。四个物体共保护 83 个不同源帧／槽位位置，其中三个搭配来自第 520 帧、一个来自第 280 帧，不能解释为四个独立正常场景。

实际检查说明求交与信号确有区别：训练 `supplement_002/180` 的包围盒机会、真实表面命中、最终异常回波为 13→9→9，`supplement_001/217` 为 6→0→0；验证 `supplement_003/520` 为 249→181→180。全部 4,524 个新增帧还原后与渲染输出逐元素相同，没有提高回波概率、挪动点或重抽信号。

历史开发池 `results/synthetic/v1/` 则包含 32 个训练世界、8 个验证世界，共 19,824 帧，曾按 val19 聚合标签统计生成与选样。它及 [旧覆盖结果](../results/coverage/v1.json) 仅保留为明确隔离的开发记录，没有进入当前实验根清单。原 40 世界的生成与选择只使用正常来源及预先规定的内容条件；生成入口不再使用 val19 参考包络或拟合分布差异。

数据生成使用 `src.generate --config protocol/data.json --workers N`。当前扩充输出为 `results/synthetic/expanded/`，按原顺序引用全部40个原世界，再加入本次生成世界；原实验池及基础世界不改写。入口拒绝覆盖已冻结的输出，未完成输出可按同一配置继续。扩充依据是物体与搭配的变化预算，不以接近 val19 分布或提高几何探针成绩为目标。

基础 32 世界的局部检查先于几何计算选定 134 帧，包含训练 53、验证 81 帧，结果在 [candidates.json](../results/coverage/candidates.json)。新增 8 世界只补查 41 帧，包含训练 24、验证 17 帧，结果在 [experiment.json](../results/coverage/experiment.json)。这些固定代表扫描的有效率不是全池覆盖率，也不是正式模型的可学习性结论。

保留的几何计算位于 [src/geometry.py](../src/geometry.py)：`ScanGeometry` 从当前坐标建立不同位置的邻域；`boundary_targets` 描述依赖正常／异常标签的可观测交界距离；`thinning_pair` 保留射线删减后的原槽位对应；`sampling_targets` 检查删减后的局部支持；`surface_targets` 和 `surface_probe` 使用插入前正常表面及当前可见支持。`local_evidence` 与 `summarize_view` 提供相应可计算性检查和汇总。依赖标签或插入前表面的量只能用于数据诊断，不能冒充真实推理可得输入。历史结果中的 C1／C2／C3 名称分别对应交界、删减支持和正常表面诊断，不再规定正式模型的三项辅助任务。

删减后的保留比例与保留点中的有效率必须分开。新增检查中，所检合格低矮远距训练为 14 帧、92 个异常点：半采样保留 46 点、四分之一保留 35 点，两者按原局部支持规则的有效数均为零。验证对应 1 帧、5 点，半采样保留 2 点而无有效支持，四分之一没有保留异常。原因主要是可靠尺度或标签组支持丢失；没有通过放宽数量条件填补结果。普通少点不等于真实远距，异常回波少也不等于整个扫描没有邻域支持。

旧正常表面诊断要求插入前参考及插入后可见支持分别不少于 20 个不同位置，并检查拟合质量、空间展开和凸包内插条件。所检训练低矮远距仅 6/92 异常点具有该参照；验证为 0/5。这个缺失说明该诊断的覆盖边界，不代表相应异常没有检测标签，也不限制新方法必须沿用同一表面目标。

复杂正常参照确实存在。验证 `supplement_000/520` 的异常槽位 `93764` 相对正常表面的竖直位移为 −0.095984 米，附近正常槽位 `89664` 为 −0.170346 米，后者偏离更大但仍正常；两者通过原表面可靠性检查。新增数据的 33 个独立查询复算与批量结果相差小于 10⁻⁶ 米。此类例子说明不能把偏离大小直接等同于异常身份，尚不能确定任何网络能否学会区分。

## 历史：80／40数量扩充

原40世界已有起步所需的正反例，但固定物体数量、形状内部变化与搭配仍有限。用户据此授权先扩充训练20至80世界、合成验证20至40世界。这是探索性数量预算，不是关于最佳样本数或检测成绩的结论。该轮训练正常来源为206，验证为201；原20个验证世界标为 `original`，新增20个标为 `added`，该轮分别报告。增加世界不会增加独立正常环境，世界帧数也不是独立物体数。

四类形状各计划新增15个训练世界、5个验证世界。每类训练由3个低矮、3个较高、3个带近远轨迹机会、2个原生正常结构搭配，以及各一组低矮和较高朝向配对组成；验证由近远机会、正常结构搭配、较高物体各一个和一组低矮朝向配对组成。低矮高度从[0.10,0.195]米提出，较高物体从[0.22,0.80]米提出；配对较高物体上限0.70米，正常结构搭配高度为[0.10,0.30]米。该轮长度、宽度和各剖面区间完整记录于 `results/synthetic/expanded/manifest.json` 的原生成配置。这些区间定义生成提案，不代表可见回波跨度。

部件半轴独立乘以[0.8,1.2]的比例，接合偏移在模板单位内扰动±0.06，组合部件绕局部竖轴旋转±0.35弧度，再接受既有连通性、支撑和轨迹碰撞检查。物体局部完整高度仍按连续几何范围计算。水平部件旋转后实际长宽可以不同于名义提出尺寸，清单记录包含所有旋转后的实际范围。没有改变形状求交、遮挡竞争、返回概率、强度标定或远距采样规则。

训练8组、验证4组朝向配对，各组共用形状、材质、支撑锚点、法向、源序列和信号种子，朝向相差90°。形状父项与其变体完整留在同一侧。普通世界按预定轨迹四分段优先寻找支持，有限预算后才在整条来源轨迹内寻找；较高物体优先搭配已有结构条件。结构条件只表示3米内存在至少两种支持语义或至少三个已知非地面正常回波，不等于精确的困难正常类别。近远提案要求支撑锚点到传感器轨迹具有小于10米及35—50米的距离机会，不根据最终回波数接纳。轨迹内的自然变化仍同时包含距离、方向、可见片段和背景，不能称为严格单因素比较。

原生正常参照沿用现有诊断计算。201侧复用既有8张扫描；206侧仅计算预定帧16、72、128、184、240、296、352、408。参照定义是有效正常位置相对局部正常参考表面高5—20厘米。选中的位置必须在插入后保留原坐标、强度和标签；实际是否与异常共同可见另行记录，不以该诊断有效率筛世界。旧三项辅助诊断不构成新数据的通过门槛。

每个几何组限定3次形状物理尝试、192次支持提案和最多12个局部合格支持；配对两侧必须同时通过整条来源轨迹的已观测障碍检查。接纳后保存所有449或682帧，包括零回波、1—4点、距离外和几何不可计算的观测。失败有记录，不无限延长种子；首次先执行计划内训练阶梯近远组和验证桥形正常搭配组，测量实际开销，再执行剩余预算。

## 当前真实几何分析

本次分析回答四个问题：几何能否区分标签；条件化是否比原始几何更有用；这些量在哪些条件下失效；类似条件下哪些正常结构容易与异常混淆。本轮几何与条件特征只由当前扫描全部实际回波的坐标计算，强度未进入这些探针。标签用于原帧的官方评价资格判断，并在无标签特征计算之后用于正常拟合样本的资格判断和最终评价、描述。依赖真实异常标签计算的异常内部邻域、距异常边界或距已知正常点距离，不得充当待评价分数的输入。

正常参考仅从 `train/206` 拟合。条件分箱的规则、双尾评分规则、特征集合与组合方式先于本次验证评分确定；需要估计的尺度分箱边界和经验分布只用 `train/206` 正常点计算。`train/201` 用于检查固定参考在另一正常来源上的误报和覆盖，不重新拟合参考。val19 标签仅用于官方资格判断、固定分数的评价及条件分布描述，不能用于选择最有利的分箱、尾方向或组合，也不能用于拟合生成器的异常尺寸、距离和数量比例。

几何计算以同一当前扫描中的不同坐标位置建立局部邻域，保留原始回波槽位身份。候选证据包括局部表面残差、表面厚度、法向变化和协方差形态，并单列按局部采样尺度归一化的量。法向、平面和尺度均从当前无标签点云估计；局部表面残差描述可见邻域，不能解释为被遮挡正常表面的真实位移。局部采样尺度同时受观测和物体几何影响，是观测条件的代理量；加入它的条件比较不能直接证明纯传感器因素的因果作用。

具体邻域为两米内最多 32 个不同坐标的最近邻，排除查询位置自身，至少需要 8 个位置。邻域中位距离记为采样尺度。协方差按邻点数归一化，升序特征值记为 $\lambda_0,\lambda_1,\lambda_2$：表面厚度为 $\sqrt{\lambda_0}$，最小方差占比为 $\lambda_0/\sum_i\lambda_i$，线性度为 $(\lambda_2-\lambda_1)/\lambda_2$，平面度为 $(\lambda_1-\lambda_0)/\lambda_2$。查询点至邻域中心平面的绝对距离为局部表面残差。法向另要求 $\lambda_1>10^{-12}$ 且 $\lambda_1-\lambda_0\geq0.05\lambda_2$；法向变化为与至少 8 个有效邻点法向之间的不定向夹角均值，单位弧度。残差与厚度除以采样尺度的版本单列。没有可靠法向时，残差和法向变化缺失，仍可靠的协方差形态不随之清空。

距离采用固定边界 2.5、5、10、20、35、50 米。射线条件仅采用传感器坐标的竖直方向分量 `ray_z=z/r`，边界为 −1、−0.3、−0.15、−0.075、−0.025、0.025、0.1、0.3、1；它不是方位角或表面入射角。由于 $z=r\,\mathrm{ray}_z$，距离与竖直射线分量合用也包含传感器坐标下的高度信息，可能同时区分不同场景结构，不能将全部收益归因于消除了采样影响。采样尺度采用 `train/206` 正常点的五等分分位数，参考取值范围外的尺度保持无参考。条件箱内每个所用几何量均须有至少 256 个有效正常点、来自至少 20 帧；这只是样本支持要求，相邻 20 帧不代表 20 个独立场景，也不保证参考足以代表所有正常结构。

最小对照使用三类固定规则，分数越高表示在正常参考下越少见。双尾经验稀有度同时检查偏小与偏大两端，包含全部同分参考点，不按真实异常标签选择方向。正常参考取值范围之外的几何量取最高稀有度。这是经验排序分数，不是经过校准的异常概率或显著性检验概率。多特征组合统一取各特征稀有度的最大值。

| 对照 | 输入与正常参考 | 回答的问题 |
| --- | --- | --- |
| A：仅观测条件 | 距离、射线竖直方向等无标签条件；加入局部采样尺度的版本另列 | 仅凭观测条件的少见程度，能够产生多少异常区分 |
| B：无条件几何 | 同一组几何量在 `train/206` 正常点上的无条件双尾经验稀有度 | 几何本身相对于全部正常参考是否少见 |
| C：条件几何 | 同一组几何量在 `train/206` 正常条件分箱内的双尾经验稀有度；距离、距离加射线方向及加入采样尺度代理的条件版本分别报告 | 在可比条件的正常参考下，几何稀有度是否提供额外区分 |

B 与 C 使用完全相同的几何特征集合和组合规则。原始量与归一化量分别比较，不能把条件化与更换特征的效果合并。A 同时给出与 C 对应的条件集合，含射线竖直方向的结果作为补充。条件分箱须达到预先规定的正常样本数与跨帧支持数；正常参考不足或几何不可计算的点不填零分，不将缺测本身当作异常证据。

主 A/B/C 评价限制在相同有效覆盖交集，沿用官方距离、标签和原始帧资格规则，不因某方法覆盖不足重新筛选合格帧。分别报告正常与异常覆盖以及远距、少回波等条件下的缺测。交集内的 AP、FPR95 和固定误报率召回仅描述该交集；没有覆盖全部官方点时，不能报告为完整 STU 指标，也不能直接与旧原型的完整 val19 指标比较。正常迁移误报、单特征结果和条件差异共同用于解释组合分数，不能仅由一个总 AP 判断科学命题。

总体组合要求六项几何同时有效，可能排除稀疏或法向不可靠的结构；单量对照采用该量自己的共同有效点集。`returns` 分组指原合格帧内全部官方异常标签点数，是依赖真值的事后描述，不是推理条件，也不是单个物体的完整点数。所有相邻帧保持所属序列，逐一排除序列时直接从总体精确分数计数中减去该序列，不重新拟合、不把点随机拆开。

阈值有两种用途：排序诊断的“误报不超过 1% 时召回率”在各评价点集上读取固定分数的整条曲线；正常迁移与分组误报使用仅由 `train/206` 确定的固定阈值。前者是开发集排序能力的描述，不能当作由正常训练得到的可部署工作点。后者在 `train/206` 上达到的误报比例属于拟合样本内结果，需要由 `train/201` 检查迁移。

这些是开发分析。条件比较的正结果支持给定特征、正常来源与覆盖条件下存在可利用关联。单变量双尾分数只检测极端取值，可能漏掉正常分布中部的低密度区，以及只体现在多变量关系中的异常；负结果只能否定本次可计算特征与比较方案，不能单独否定所有可能的局部几何证据。合成世界的补充、监督选择和模型设计应依据具体证据决定；这里的探针结果不确定正式模型方案。

A 仅使用各条件边际稀有度的最大值，未建立条件的联合分布；C 超过 A 只能说明超过此明确基线。距离与射线方向也关联场景内容，C 超过 B 表明本次正常参考变换改善了区分，不能据此识别纯采样因素的因果作用。

## 现有合成数据的针对性核查

本次只检查既有数据能否提供学习几何区别所需的正反例。原始正常侧先读取此前按帧固定抽样的 `206/201` 缓存，每个源帧只出现一次；随后在当前 40 个世界中复用既有选择规则，检查 155 张代表扫描。另按清单中 35—50 米可见帧数最多、世界名破同分的规则，每侧预选 `candidate_011` 的完整轨迹，共 449 和 682 帧。两部分重合帧只计算一次，合计 1,276 个世界帧、1,131 个唯一原始帧。代表扫描与两条轨迹分别汇总；代表扫描比例不代表全部 22,620 个世界帧的发生比例，世界数量不代表独立正常环境数量。
